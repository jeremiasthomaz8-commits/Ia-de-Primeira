# IA de Primeira — Guia de marca

Experiência em português brasileiro, construída com HTML, CSS e JavaScript nativos. Sem instalação de dependências.

Execute `npm run dev` nesta pasta e abra http://127.0.0.1:4173. O conteúdo publicável está em `dist/`. Execute `npm run check` para verificar a sintaxe do JavaScript.

Inclui quatro capítulos, índice modal acessível, navegação por âncoras, animações com redução de movimento, paleta copiável, teste tipográfico, UI Kit local e visualização ampliada dos mockups. Os dados de produto são ilustrativos e não são enviados a serviços externos.

Os 12 SVGs fornecidos são preservados em `dist/assets/logos`. O download ZIP inclui todos os originais. Os três mockups foram fornecidos pelo cliente. A família principal Isidora Sans é carregada localmente por `dist/fonts.css`, com sete pesos (100, 300, 400, 500, 600, 700 e 900) e versões em itálico. Os 14 TTFs originais estão em `dist/assets/fonts`; não há dependência de fontes externas. Os SVGs da marca permanecem intactos. A grade é ilustrativa. Área de proteção (H/4) e tamanhos mínimos (assinatura: 160 px / 35 mm; símbolo: 24 px / 6 mm) estão documentados como proposta técnica para validação, não como regras aprovadas. Os limites impressos exigem provas nos suportes finais.

Referência de estrutura e direção visual: https://vaultx-brand.framer.website/ . A paleta, o conteúdo e os materiais visuais pertencem à identidade IA de Primeira.


O conteúdo posiciona a marca como uma casa de cursos, treinamentos e palestras. A implantação de IA aparece como serviço complementar. O UI Kit demonstra uma trilha de aprendizagem local, com inclusão, busca e pausa de estudos.
